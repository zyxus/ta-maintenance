# Техноавиа — временная страница

Минимальное приложение Laravel 13 / PHP 8.3+. Один маршрут `/`, один шаблон Blade, обычный CSS и локальное изображение. Без БД, миграций, авторизации, сессий в запросе страницы, JavaScript, Node.js и npm. Встроенные в Laravel компоненты БД не используются.

## Запуск

Нужны PHP 8.3+ и Composer 2, а также стандартные расширения Laravel: Ctype, cURL, DOM, Fileinfo, Filter, Hash, Mbstring, OpenSSL, PCRE, PDO, Session, Tokenizer, XML. Расширение PDO требуется фреймворку; сервер базы данных и подключение к БД не нужны.

```sh
cd technoavia-maintenance
composer install --no-dev --optimize-autoloader
php artisan serve --host=127.0.0.1 --port=8000
```

Открыть http://127.0.0.1:8000. `composer install` автоматически копирует `.env.example` в `.env` и создает уникальный APP_KEY. Существующий `.env` и заполненный ключ сохраняются. Не отключайте Composer scripts. Если установка выполнена с `--no-scripts`, выполните `php artisan package:discover` и `php scripts/setup.php` вручную.

## Размещение на сервере

1. Распакуйте проект и выполните `composer install --no-dev --optimize-autoloader`.
2. В `.env` задайте `APP_URL=https://ваш-домен`; оставьте `APP_ENV=production` и `APP_DEBUG=false`.
3. Направьте корень сайта (DocumentRoot) **в папку `public/`**, а не в корень проекта. Для Nginx есть пример `deploy/nginx.conf.example`: замените домен, путь и сокет PHP-FPM. HTTPS настройте средствами своего сервера. Для Apache включите mod_rewrite и AllowOverride All; `.htaccess` уже включен.
4. Пользователь PHP-FPM должен иметь право записи в `storage/` и `bootstrap/cache/`. Настройте владельца/группу по правилам сервера; не используйте chmod 777.
5. При желании: `php artisan optimize`.

`artisan serve` предназначен для локальной проверки. Для рабочего сайта используйте Nginx/Apache и PHP-FPM. Команды миграций, создание БД и `php artisan down` не нужны: сама главная страница уже является заглушкой.

Маршрут `/` возвращает HTTP 200. Неизвестные адреса возвращают стандартный 404 Laravel. Заглушка не отключает другие приложения на сервере: ее следует подключить к нужному домену силами администратора.

## Что где менять

- Текст и ссылка: `resources/views/maintenance.blade.php`.
- Верстка: `public/assets/style.css`.
- Человек в спецодежде: `public/assets/worker.png`.
- Название в шапке набрано текстом; это не официальный векторный логотип.

На широком экране текст слева, человек справа. На телефоне изображение расположено под текстом и кнопкой. Все ресурсы входят в архив, внешних шрифтов/CDN нет.

Из прошлого чата было доступно только исходное изображение сайта. Персонаж в этой версии воссоздан встроенным ImageGen по мужчине справа на исходном скриншоте; это не извлеченный файл ранее сгенерированного макета. Сведения о подготовке изображения — в `ASSET-NOTES.md`.
